# Заглушка агента

`fake-agent.mjs` изображает GigaCode CLI для тестов: печатает записанный поток
событий настоящего CLI (`tests/agent/qwen-code-0.24.4/`) и выходит с его кодом.
Сценарий выбирается переменной окружения `FAKE_AGENT_SCENARIO`:

| Сценарий | Что делает |
|---|---|
| `write` (по умолчанию) | поток записи файла, файл `notes.md` действительно создаётся, код 0 |
| `read` | поток чтения, код 0 |
| `toolbudget` | обрыв по пределу вызовов, код 55 и текст ошибки CLI |
| `walltime` | обрыв по пределу времени, код 55 |
| `apierror` | ошибка API, код 1 |
| `hang` | печатает начало потока и ждёт сигнала — для остановки и сторожевого таймера |
| `unknown` | вставляет событие неизвестного типа и обрывает последнюю строку |
| `echo-prompt` | печатает полученный промпт как текст модели |

Если задан `FAKE_AGENT_SCENARIO_FILE` и файл существует, сценарий читается из
него — так сквозные тесты меняют сценарий без перезапуска IDE.

`FAKE_AGENT_LEGACY=1` убирает `stream-json` из `--help` — сборка без потокового
вывода. Промпт и аргументы дописываются в файл `FAKE_AGENT_LOG`, если он задан.
