# Change: коэффициент полезности файлов контекста

## Why

Контроль контекста показывает, сколько весит каждый файл, и отдельными
замечаниями — повторы, ненайденные пути и отставание от кода. Но ответа на
вопрос «какая часть этих токенов работает на агента» нет: файл в 3 000
токенов, где треть — копия общего контекста, заготовки шаблона и абзацы про
переименованные классы, выглядит в таблице так же, как плотный файл того же
размера. Решать, что сжимать первым, приходится чтением.

Полезность без запусков агента не измерить. Но долю балласта и привязку текста
к коду можно оценить по тому, что карта уже знает, и свести в одно число с
понятной разбивкой.

## What Changes

- **Коэффициент полезности файла** — эвристика из трёх множителей:
  плотность (доля токенов без балласта) × (0,5 + 0,5 × привязка к коду) ×
  свежесть. Балласт — абзацы-повторы, заготовки (HTML-комментарии, `TODO`,
  «заполнить», одни `<…>`) и абзацы со ссылкой на путь, которого нет; пустой
  файл — балласт целиком. Привязка — доля текста `context.md` с `` `кодом` ``
  или ссылкой. Свежесть — по отставанию `context.md` от кода:
  10 коммитов — множитель 0,5.
- **Полезные токены** у каждого файла, в сумме по контексту, по набору модуля
  и по набору из нескольких узлов.
- **Сведение `low-usefulness`**: файл от 200 токенов с коэффициентом ниже
  50 % — с причинами (сколько токенов в повторах, заготовках, абзацах с
  битыми путями, какая привязка и множитель свежести). Попадает в панель
  «Проблемы» уровнем Information и в проверку `context` команды
  `openspec-ide-check`; код завершения при пороге по умолчанию не меняет.
- **Раздел «Контекст»**: в виде «Контроль» — карточка «Полезность» с
  файлами, где есть потери, и разбивкой по причинам; столбец «Полезных» у
  наборов модулей; полезные токены в сводке раздела и в карточке модуля.
- HTML-комментарии больше не участвуют в поиске повторов: это подсказки
  шаблона, а не текст, и теперь они учитываются как заготовки.
- Макеты — `docs/mockups/context-usefulness.html`.

Не входит: оценка по запускам агента (что агент прочитал, абляция «с файлом /
без файла»), проверка существования идентификаторов кода из `` `кода` ``,
настройка порогов и весов.

## Impact

- **Код**: `packages/core/src/contextControl.ts` — `measureUsefulness`,
  абзацы без HTML-комментариев; `packages/core/src/contextMap.ts` —
  `usefulness` у файла, `usefulTokens` карты и набора, `bundleUsefulTokens`
  модуля, замечание `low-usefulness`; `packages/web` — карточка
  «Полезность», столбец наборов, сводка и карточка модуля.
- **API**: `GET /api/context-map` отдаёт новые поля, прежние не меняются;
  ревизия API — 10.
- **Файлы проекта**: не меняются.
