# Spec Delta: context-map

## ADDED Requirements

### Requirement: Набор контекста из нескольких узлов

Раздел «Контекст» ДОЛЖЕН (SHALL) позволять собрать набор контекста из
нескольких модулей, доменов и ADR щелчками по ним на графе и в матрице:
щелчок в режиме набора (или Ctrl/⌘/Shift+щелчок вне его) ДОЛЖЕН добавлять
узел в набор, повторный — убирать. Набор ДОЛЖЕН включать общий контекст,
`context.md` выбранных модулей и транзитивно их зависимостей по `depends_on`,
спеки доменов этих модулей и выбранных доменов, ADR, ссылающиеся на модули
набора или выбранные домены, и выбранные ADR. Добавление зависимостей и спек
доменов модулей ДОЛЖНО отключаться. Каждый файл ДОЛЖЕН входить в набор один
раз; узлы вне набора ДОЛЖНЫ быть приглушены на графе.

#### Scenario: Модуль и домен другого модуля

- **WHEN** пользователь в режиме набора щёлкает модуль `sds-impl` и домен `cm-cluster-api`
- **THEN** в наборе `context.md` модуля `sds-impl`, спеки `replication`, `servant-master-api` и `cm-cluster-api` и ADR модуля
- **AND** `context.md` модуля `sds-master` в набор не входит

#### Scenario: Только выбранные домены

- **WHEN** в наборе модуль `sds-impl` и домен `cm-cluster-api`, а флажок «спеки доменов модулей» снят
- **THEN** из спек в наборе остаётся только `cm-cluster-api`

#### Scenario: Повторный щелчок

- **WHEN** пользователь щёлкает по узлу, который уже в наборе
- **THEN** узел убирается из набора, а файлы, которые давал только он, — из списка

#### Scenario: Ctrl+щелчок без режима

- **WHEN** режим набора выключен и пользователь щёлкает домен с нажатым Ctrl
- **THEN** домен добавляется в набор и открывается панель набора

#### Scenario: Копирование набора

- **WHEN** пользователь нажимает «Копировать пути» в панели набора
- **THEN** в буфер обмена попадают пути набора по одному в строке с префиксом `@`
