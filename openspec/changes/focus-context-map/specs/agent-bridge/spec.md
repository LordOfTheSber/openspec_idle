# Spec Delta: agent-bridge

## REMOVED Requirements

### Requirement: Настройка подключения к GigaCode CLI

**Reason**: Запуск агента из IDE удалён: агентов запускают вне IDE, а IDE готовит для них контекст.
**Migration**: Настройки агента задаются в самом агенте; набор файлов контекста для модуля берётся в разделе «Контекст».

### Requirement: Проверка доступности агента

**Reason**: Агент больше не запускается из IDE.
**Migration**: Не требуется.

### Requirement: Сборка промпта из инструкций OpenSpec

**Reason**: Промпт собирает агент или пользователь; IDE отдаёт список файлов контекста модуля.
**Migration**: Используйте «Копировать пути» в карточке модуля раздела «Контекст» и инструкции `openspec instructions`.

### Requirement: Запуск агента и потоковый вывод

**Reason**: Агент больше не запускается из IDE.
**Migration**: Запускайте агента в терминале; изменения файлов IDE подхватывает наблюдением за `openspec/`.

### Requirement: Бюджеты запуска

**Reason**: Агент больше не запускается из IDE.
**Migration**: Бюджеты задаются параметрами самого агента.

### Requirement: Режим подтверждения действий агента

**Reason**: Агент больше не запускается из IDE.
**Migration**: Режим подтверждения задаётся параметрами самого агента.

### Requirement: Журнал запусков и связь с метриками

**Reason**: Запусков из IDE больше нет, журнал не пополняется.
**Migration**: Уже записанная история запусков остаётся в метриках задач.
