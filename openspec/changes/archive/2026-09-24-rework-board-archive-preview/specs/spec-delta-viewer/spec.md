# Spec Delta: spec-delta-viewer

## ADDED Requirements

### Requirement: Вкладка «После архивации»

Просмотр дельт change ДОЛЖЕН (SHALL) иметь вкладку «После архивации», которая
показывает предпросмотр архивации этого change: исход, затрагиваемые capability
и изменения основных спеков по требованиям, сценариям и строкам. Вкладка ДОЛЖНА
строить предпросмотр только при её открытии.

#### Scenario: Открытие вкладки

- **WHEN** пользователь в разделе «Дельты» переключается на вкладку «После архивации»
- **THEN** показывается предпросмотр архивации выбранного change

#### Scenario: Вкладка не открыта

- **WHEN** пользователь просматривает дельты на вкладке «Дельты»
- **THEN** прогон архивации на временной копии не выполняется
