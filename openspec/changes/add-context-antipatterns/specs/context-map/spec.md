# Spec Delta: context-map

## ADDED Requirements

### Requirement: Антипаттерны контекста по токенам

Система ДОЛЖНА (SHALL) искать в каждом файле контекста — общем контексте,
`context.md` модулей, спеках доменов и действующих ADR — антипаттерны, за
которые агент платит токенами без пользы, и для каждой находки оценивать
токены, которые уйдут при исправлении, той же эвристикой, что и объём.
Система ДОЛЖНА находить: текст не на английском (файл от 200 токенов, где не
меньше 30 % букв — не латиница); блоки кода от 500 токенов; base64, hex от
40 символов и `data:`-адреса; эмодзи, псевдографику и строки-разделители от
10 токенов на файл; от 5 HTML-тегов в прозе; от 3 вводных фраз без смысла; от
3 слов капсом или `!!` в прозе. Нормативные слова спек (`SHALL`, ДОЛЖЕН,
`WHEN`, `THEN`), аббревиатуры, стрелки и типографика, шаблоны вида `<папка>`,
`` `код` ``, HTML-комментарии и frontmatter антипаттернами НЕ ДОЛЖНЫ
считаться. Каждая находка ДОЛЖНА давать сведение со строкой первого
вхождения (у языка — на весь файл) и оценкой экономии; экономия файла —
сумма находок, но не больше его токенов. Недействующие ADR НЕ ДОЛЖНЫ
проверяться.

#### Scenario: Русский текст в контексте модуля

- **WHEN** `context.md` модуля `sds-master` в 600 токенов написан по-русски
- **THEN** у файла есть сведение о тексте не на английском с долей букв не латиницей и оценкой экономии
- **AND** экономия меньше токенов файла

#### Scenario: Капс в общем контексте

- **WHEN** общий контекст содержит строку «ВНИМАНИЕ!! НИКОГДА не правьте конфигурацию руками, ОБЯЗАТЕЛЬНО через CLI»
- **THEN** у файла есть сведение о капсе на этой строке с примером «ВНИМАНИЕ»

#### Scenario: Нормативные слова спеки — не капс

- **WHEN** спека домена содержит «Система ДОЛЖНА (SHALL) отдавать JSON по HTTP» и сценарии с WHEN/THEN
- **THEN** сведения о капсе у спеки нет

#### Scenario: Антипаттерны в CI

- **WHEN** `openspec-ide-check --only context` запущен в проекте, где в `context.md` модуля вставлен листинг на 60 строк
- **THEN** в отчёте есть сведение о большом блоке кода на строке его начала с оценкой токенов
- **AND** код завершения при пороге по умолчанию — 0

### Requirement: Антипаттерны в виде «Контроль»

Вид «Контроль» раздела «Контекст» ДОЛЖЕН (SHALL) показывать карточку
«Антипаттерны»: сколько токенов можно сэкономить во всём контексте и их долю,
и файлы с находками по убыванию экономии — с находками и экономией каждой.
Файлы без находок в таблицу НЕ ДОЛЖНЫ входить.

#### Scenario: Файл с капсом в карточке

- **WHEN** пользователь открывает вид «Контроль» в проекте, где в общем контексте `2.md` есть капс, а в `1.md` антипаттернов нет
- **THEN** в карточке «Антипаттерны» виден `2.md` с находкой «капс» и оценкой экономии
- **AND** `1.md` в таблице нет
