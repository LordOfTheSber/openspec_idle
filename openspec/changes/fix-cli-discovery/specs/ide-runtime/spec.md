# Spec Delta: ide-runtime

## ADDED Requirements

### Requirement: Поиск CLI OpenSpec

Система ДОЛЖНА (SHALL) искать исполняемый файл CLI OpenSpec в таком порядке:
явно заданный путь (настройка IDE или переменная `OPENSPEC_CLI`), затем
`node_modules/.bin` проекта и выше по дереву, затем PATH, затем каталоги
глобальной установки npm. Явно заданный путь, по которому CLI нет, НЕ ДОЛЖЕН
подменяться найденным в другом месте. Уведомление об отсутствии CLI ДОЛЖНО
объяснять, как указать путь, и перечислять просмотренные места.

#### Scenario: CLI установлен глобально, но не виден в PATH процесса

- **WHEN** CLI лежит в каталоге глобальной установки npm, которого нет в PATH процесса IDE
- **THEN** CLI находится, и проект читается без дополнительных действий

#### Scenario: Путь скопирован из Git Bash

- **WHEN** на Windows задан путь вида `/c/Users/dev/AppData/Roaming/npm/openspec`
- **THEN** он переводится в путь Windows, и находится `openspec.cmd` рядом с ним

#### Scenario: Неверный явный путь

- **WHEN** задан путь, по которому исполняемого файла нет, а в проекте CLI есть
- **THEN** показывается уведомление, что CLI не найден по заданному пути
- **AND** CLI из проекта не используется
