# Spec Delta: vscode-extension

## ADDED Requirements

### Requirement: Путь к CLI OpenSpec в настройках

Расширение ДОЛЖНО (SHALL) предоставлять настройку `openspec.cliPath` с путём к
CLI OpenSpec или каталогу с ним. Изменение настройки ДОЛЖНО применяться без
перезапуска VS Code, а команда «Обновить» при отсутствии CLI ДОЛЖНА искать его
заново. Сообщение об отсутствии CLI ДОЛЖНО предлагать открыть эту настройку.

#### Scenario: Путь исправлен в настройках

- **WHEN** расширение в состоянии «нет CLI» и пользователь указывает верный путь в `openspec.cliPath`
- **THEN** бэкенд перезапускается, и дерево показывает проект

#### Scenario: Команда без CLI

- **WHEN** CLI не найден и пользователь вызывает команду, которой нужен проект
- **THEN** предупреждение объясняет, почему CLI из терминала может быть не виден
- **AND** предлагает кнопку «Указать путь к CLI», открывающую настройку
