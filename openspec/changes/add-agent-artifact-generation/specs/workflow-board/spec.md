# Spec Delta: workflow-board

## ADDED Requirements

### Requirement: Генерация артефактов с доски

Форма создания change на доске ДОЛЖНА (SHALL) принимать необязательный замысел
изменения и, если он указан, предлагать сразу сгенерировать агентом первый
артефакт схемы — тот, в колонке которого появится карточка. Панель деталей
change ДОЛЖНА у каждого несозданного артефакта предлагать генерацию агентом.

#### Scenario: Новый change с замыслом

- **WHEN** пользователь создаёт change с замыслом и отмеченной генерацией
- **THEN** после создания открывается раздел «Агент» для этого change с запуском по первому артефакту схемы
- **AND** промпт содержит замысел

#### Scenario: Новый change без замысла

- **WHEN** пользователь создаёт change, не указав замысел
- **THEN** change создаётся, раздел не переключается

#### Scenario: Генерация из панели деталей

- **WHEN** у change нет design и пользователь нажимает «Сгенерировать» у design в панели деталей
- **THEN** открывается раздел «Агент» с запуском по артефакту design
