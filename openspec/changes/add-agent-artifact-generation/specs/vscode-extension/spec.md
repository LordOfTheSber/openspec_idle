# Spec Delta: vscode-extension

## ADDED Requirements

### Requirement: Генерация артефакта агентом в VS Code

Выбор отсутствующего артефакта в дереве ДОЛЖЕН (SHALL) предлагать создание
пустым по шаблону или генерацию агентом с необязательным замыслом. Команда
«Создать change» ДОЛЖНА после создания предлагать описать замысел и
сгенерировать первый артефакт схемы. Генерация ДОЛЖНА открывать панель
разделов на разделе «Агент» с выбранным change, артефактом и замыслом.
Сообщение навигации с целью агента ДОЛЖНО проходить разбор протокола и
отклоняться при некорректном артефакте или замысле.

#### Scenario: Генерация из дерева

- **WHEN** пользователь выбирает отсутствующий proposal в дереве и выбирает «Сгенерировать агентом» с замыслом
- **THEN** открывается панель на разделе «Агент» с запуском по proposal этого change
- **AND** промпт содержит замысел

#### Scenario: Создание change с замыслом

- **WHEN** пользователь создаёт change командой палитры и вводит замысел
- **THEN** панель открывается на разделе «Агент» с запуском по первому артефакту схемы

#### Scenario: Замысел не введён

- **WHEN** пользователь создаёт change и оставляет замысел пустым
- **THEN** change создаётся, панель не открывается

#### Scenario: Некорректная цель в навигации

- **WHEN** в сообщении навигации артефакт содержит `../`
- **THEN** сообщение отклоняется
