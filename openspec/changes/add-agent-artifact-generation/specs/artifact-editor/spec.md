# Spec Delta: artifact-editor

## ADDED Requirements

### Requirement: Выбор способа создания артефакта

Везде, где интерфейс предлагает создать отсутствующий артефакт change, система
ДОЛЖНА (SHALL) предлагать два способа: пустой по шаблону схемы и генерацию
агентом. Генерация агентом ДОЛЖНА открывать раздел «Агент» для этого change с
выбранным артефактом и собранным промптом, не запуская агента без
подтверждения. Если у артефакта в схеме нет инструкции, генерация агентом НЕ
ДОЛЖНА предлагаться.

#### Scenario: Генерация из встроенного редактора

- **WHEN** пользователь открывает отсутствующий артефакт design и выбирает «Сгенерировать агентом»
- **THEN** открывается раздел «Агент» с запуском по артефакту design
- **AND** агент не запущен, пока пользователь не подтвердит запуск

#### Scenario: Пустой по шаблону

- **WHEN** пользователь выбирает «Пустой по шаблону»
- **THEN** артефакт создаётся из шаблона схемы, как раньше

#### Scenario: Артефакт без инструкции

- **WHEN** схема не заполнила инструкцию артефакта
- **THEN** предлагается только создание по шаблону
