# Spec Delta: agent-bridge

## ADDED Requirements

### Requirement: Генерация артефакта агентом

Запуск агента по артефакту ДОЛЖЕН (SHALL) принимать необязательный замысел
автора — текст о том, что должно получиться, — и включать его в промпт
отдельным разделом рядом с инструкцией схемы. Замысел ДОЛЖЕН сохраняться в
записи о запуске вместе с целью. Если запуск по артефакту открыт как генерация
артефакта, а в настройках выбран режим `plan` или `default`, окно подтверждения
ДОЛЖНО предлагать режим `auto-edit` и объяснять причину; настройки при этом НЕ
ДОЛЖНЫ меняться. Запуск по-прежнему ДОЛЖЕН выполняться только после
подтверждения пользователя.

#### Scenario: Замысел в промпте

- **WHEN** пользователь генерирует proposal с замыслом «выгрузка данных пользователя в CSV»
- **THEN** промпт содержит раздел «Замысел автора» с этим текстом
- **AND** содержит инструкцию схемы для proposal и путь файла

#### Scenario: Генерация без замысла

- **WHEN** пользователь генерирует design, не указав замысел
- **THEN** промпт собирается из инструкции схемы без раздела замысла

#### Scenario: Режим по умолчанию не пишет файлы

- **WHEN** в настройках агента выбран режим `default`, а пользователь генерирует артефакт
- **THEN** в окне подтверждения выбран режим `auto-edit`
- **AND** показано, что в режиме `default` неинтерактивный запуск отклоняет правку файлов

#### Scenario: Режим из настроек позволяет писать файлы

- **WHEN** в настройках выбран режим `auto-edit` или `auto`
- **THEN** для генерации артефакта используется режим из настроек

#### Scenario: Слишком длинный замысел

- **WHEN** замысел длиннее 4000 символов
- **THEN** в промпт попадают первые 4000 символов
