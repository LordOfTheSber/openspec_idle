# Spec Delta: vscode-extension

## ADDED Requirements

### Requirement: Нарушения структуры в панели «Проблемы»

Расширение ДОЛЖНО (SHALL) показывать нарушения структуры папок в панели
«Проблемы»: лишний файл — на самом файле, остальные нарушения и ошибки
описания — на строке правила в `openspec/structure.yaml`. Проверка ДОЛЖНА
выполняться при активации, при изменении файлов рабочей области, при
сохранении описания и по команде «Проверить структуру папок». Исправленные
нарушения ДОЛЖНЫ исчезать после следующей проверки. Раздел «Структура» ДОЛЖЕН
открываться в панели разделов.

#### Scenario: Лишний файл в строгой папке

- **WHEN** пользователь создаёт `docs/context/draft.txt` в строгой папке
- **THEN** в панели «Проблемы» появляется ошибка на файле `draft.txt`

#### Scenario: Нет обязательного файла

- **WHEN** описание требует `docs/context/README.md`, а файла нет
- **THEN** ошибка показывается на строке этого правила в `openspec/structure.yaml`

#### Scenario: Нарушение исправлено

- **WHEN** пользователь удаляет лишний файл
- **THEN** ошибка исчезает из панели «Проблемы»

#### Scenario: Описания нет

- **WHEN** в проекте нет `openspec/structure.yaml`
- **THEN** в панели «Проблемы» нет замечаний о структуре
