# Spec Delta: ide-runtime

## ADDED Requirements

### Requirement: Строка замечания валидации

IDE ДОЛЖНА (SHALL) привязывать замечание валидации к строке файла, когда CLI
строки не сообщает, но место можно определить: для основного спека — по пути
замечания `requirements[N]` или `requirements.N…` (строка заголовка N+1-го
требования) и `overview`/`purpose` (строка `## Purpose`); для change — по имени
требования в тексте замечания (`MODIFIED "Имя"`, `header "### Requirement:
Имя"`, `Requirement "Имя"`), которое ищется в файле дельты без учёта регистра
и лишних пробелов. Если место определить нельзя, замечание ДОЛЖНО оставаться
на файле без строки.

#### Scenario: Замечание по индексу требования

- **WHEN** CLI сообщает для спека замечание с путём `requirements[1]`
- **THEN** замечание привязано к строке заголовка второго требования этого спека

#### Scenario: Замечание называет требование дельты

- **WHEN** CLI сообщает `MODIFIED "Выгрузка данных" omits scenario(s)…` для файла `data-export/spec.md` change
- **THEN** замечание привязано к строке `### Requirement: Выгрузка данных` в этом файле

#### Scenario: Требование не найдено

- **WHEN** названного в замечании требования нет в файле
- **THEN** замечание привязано к файлу без строки
