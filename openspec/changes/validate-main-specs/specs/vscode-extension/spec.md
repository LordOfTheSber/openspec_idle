# Spec Delta: vscode-extension

## ADDED Requirements

### Requirement: Диагностика основных спеков

Расширение ДОЛЖНО (SHALL) показывать замечания
`openspec validate --specs --strict` в панели «Проблемы» на файлах основных
спеков `openspec/specs/**/spec.md` с уровнем замечания. Проверка ДОЛЖНА
выполняться при активации, при изменении файлов в `openspec/specs/` — в том
числе после архивации change — и по команде «OpenSpec: Проверить основные
спеки». Исправленные замечания ДОЛЖНЫ исчезать после следующей проверки и не
ДОЛЖНЫ затрагивать замечания активных changes.

#### Scenario: Требование без сценария в основном спеке

- **WHEN** в основном спеке у требования нет ни одного сценария
- **THEN** в панели «Проблемы» появляется ошибка на строке заголовка этого требования

#### Scenario: Спек исправлен

- **WHEN** пользователь добавляет сценарий и сохраняет спек
- **THEN** ошибка исчезает из панели «Проблемы»

#### Scenario: Команда проверки

- **WHEN** пользователь выполняет «OpenSpec: Проверить основные спеки», а замечаний нет
- **THEN** расширение сообщает, что основные спеки проходят проверку, с их числом

#### Scenario: Архивация меняет спеки

- **WHEN** архивация change изменила основной спек
- **THEN** основные спеки проверяются заново без действий пользователя
