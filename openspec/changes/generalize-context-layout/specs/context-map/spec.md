# Spec Delta: context-map

## ADDED Requirements

### Requirement: Произвольная раскладка контекста

Система ДОЛЖНА (SHALL) распознавать роли файлов `openspec/context/` по
правилам, а не по именам разделов: `.md` в корне — общий контекст; `.md` в
`adr/` и её подпапках, кроме `README.md`, — ADR; папка на любой глубине, кроме
`adr/`, с файлом `00-start-here.md` или `index.md` — модуль, метаданные которого
— frontmatter этого файла (при обоих — `00-start-here.md`). Файлами модуля
ДОЛЖНЫ считаться все `.md` его папки и её подпапок, которые сами не модули;
файл метаданных ДОЛЖЕН входить в набор, только если в нём есть текст кроме
frontmatter и заголовков, и тогда — первым. Папка без файла метаданных, под
которой есть модули, ДОЛЖНА считаться группой, а её `.md` — общим контекстом
всех модулей под ней. Папка глубже раздела без файла метаданных и без модулей
под ней, в которой есть `.md` или нет ничего, ДОЛЖНА давать ошибку «нет файла
метаданных». Идентификатор модуля без поля `module` ДОЛЖЕН браться из последней
папки пути, раздел — из первой. Файлы модуля и группы ДОЛЖНЫ упорядочиваться
по имени с числами по значению. Прежняя раскладка `modules/<папка>/index.md` и
`context.md` ДОЛЖНА работать без изменений.

#### Scenario: Модуль из нумерованных частей

- **WHEN** в `openspec/context/modules/back/master/` лежат `00-start-here.md` с frontmatter и маршрутом чтения и части `01-product-context.md` … `05-testing-and-quality.md`
- **THEN** на карте модуль `master` раздела `modules` с папкой `modules/back/master`
- **AND** в его наборе `00-start-here.md`, затем части `01`…`05` по номерам
- **AND** замечаний «нет `index.md`» и «файл вне наборов» нет

#### Scenario: Модуль конфигурации без части тестирования

- **WHEN** у модуля `conf` нет `05-testing-and-quality.md`
- **THEN** замечания об этом нет, в набор идут его остальные части

#### Scenario: Общий контекст группы

- **WHEN** в `openspec/context/modules/back/` лежит `03-engineering-standards.md`, а в её подпапках — модули `master` и `cm`
- **THEN** этот файл входит в набор каждого из модулей перед их собственными файлами
- **AND** в набор модуля `conf` вне группы он не входит

#### Scenario: Новый раздел

- **WHEN** рядом с `modules/` появляется `functions/billing/00-start-here.md`
- **THEN** на карте модуль `billing` раздела `functions` со своими связями и набором

#### Scenario: Прежний index.md без текста

- **WHEN** модуль описан `index.md` из frontmatter и заголовка и `context.md`
- **THEN** в набор модуля входит только `context.md`

#### Scenario: Папка модуля без файла метаданных

- **WHEN** в `openspec/context/modules/ui/` есть `01-product-context.md`, но нет ни `00-start-here.md`, ни `index.md`, и модулей под ней нет
- **THEN** сообщается ошибка «нет файла метаданных» для папки `modules/ui`

#### Scenario: Файл не .md в папке модуля

- **WHEN** рядом с `00-start-here.md` лежит `diagram.png`
- **THEN** он отмечен как файл вне наборов, а `.md` той же папки входят в набор модуля

### Requirement: Контроль частей модуля

Система ДОЛЖНА (SHALL) применять контроль контекста ко всем файлам модуля и
группы: пустой файл модуля, кроме файла метаданных, ДОЛЖЕН давать
предупреждение на этом файле; модуль без файлов контекста — предупреждение
«загружать нечего»; повторы и пути в тексте ДОЛЖНЫ проверяться в группах и во
всех файлах модулей; привязка и свежесть ДОЛЖНЫ учитываться у всех файлов
модуля. Свежесть модуля ДОЛЖНА считаться от последнего коммита любого его файла,
незакоммиченная правка любого файла модуля — делать контекст свежим.

#### Scenario: Пустая часть

- **WHEN** `05-testing-and-quality.md` модуля `master` содержит только заголовок
- **THEN** сообщается предупреждение на этом файле с именем модуля

#### Scenario: Свежесть по любой части

- **WHEN** после коммитов в коде модуля закоммичена правка его `02-architecture.md`
- **THEN** контекст модуля не отстаёт от кода

#### Scenario: Весь контекст в файле метаданных

- **WHEN** у модуля есть только `00-start-here.md` с frontmatter и текстом
- **THEN** предупреждения «загружать нечего» нет, файл входит в набор

### Requirement: Создание модуля в раскладке проекта

Команда «Создать модуль…» ДОЛЖНА (SHALL) принимать имя в kebab-case, при
желании с группами через `/` (`back/router`), и заводить папку
`openspec/context/modules/<имя>/` с файлом метаданных и первым файлом
контекста в раскладке проекта: `index.md` и `context.md`, если все модули
проекта описаны `index.md`, иначе `00-start-here.md` и `01-product-context.md`.
Существующую папку команда НЕ ДОЛЖНА трогать.

#### Scenario: Модуль в группе

- **WHEN** в проекте с нумерованными частями пользователь создаёт модуль `back/router`
- **THEN** появляются `openspec/context/modules/back/router/00-start-here.md` с `module: router` и `01-product-context.md`

#### Scenario: Проект на прежней раскладке

- **WHEN** все модули проекта описаны `index.md`, и пользователь создаёт модуль `core`
- **THEN** появляются `openspec/context/modules/core/index.md` и `context.md`

#### Scenario: Недопустимое имя

- **WHEN** пользователь вводит `../x` или `Back/Router`
- **THEN** модуль не создаётся, показывается ошибка о формате имени
