# Change: десктопное приложение OpenSpec IDE

## Why

Сейчас IDE — локальный сервер, который открывает вкладку браузера. Для работы
это неудобно:

- запуск только из консоли, в каталоге проекта; на Windows это Git Bash или
  PowerShell и ручная сборка из исходников;
- интерфейс теряется среди вкладок браузера, у него нет своего окна, значка в
  панели задач и системного меню;
- второй репозиторий — второй процесс в консоли и вторая вкладка, и понять,
  какая вкладка к какому репозиторию относится, можно только по адресу;
- нет стартового экрана: нельзя выбрать папку репозитория мышью или открыть
  недавний;
- CLI OpenSpec приходится ставить в каждый проект отдельно, иначе IDE не
  запускается.

Команда работает с IDE каждый день, поэтому она должна быть обычным
приложением: установщик, ярлык, окно, недавние репозитории.

## What Changes

- Новый пакет `packages/desktop` — приложение на Electron. Сервер IDE работает
  внутри процесса приложения, интерфейс — в собственном окне, а не в браузере.
- Установщик для Windows (`.exe`) и переносимая сборка без установки; сборки
  для macOS и Linux из того же кода.
- Стартовый экран: открыть папку системным диалогом, список недавних
  репозиториев, предложение завести OpenSpec в папке, где его нет.
- Одно окно на репозиторий. Повторное открытие того же репозитория переводит
  фокус на его окно, а не запускает второй экземпляр.
- Системное меню и горячие клавиши.
- CLI OpenSpec входит в поставку приложения: если в репозитории нет своей
  версии, используется встроенная.
- Команда `openspec-ide` и режим браузера сохраняются — для тех, кто работает
  удалённо или в терминале. Приложение принимает путь к репозиторию аргументом.
- Закрытие окна с выполняющимся запуском агента требует подтверждения.

## Capabilities

### New Capabilities

- `desktop-shell`: десктопное приложение — установка, окна, стартовый экран,
  недавние репозитории, меню, встроенный сервер и встроенный CLI OpenSpec.

### Modified Capabilities

Нет. Требования `ide-runtime` из change `add-openspec-ide` остаются в силе:
команда `openspec-ide` с режимом браузера не удаляется, приложение добавляется
рядом.

## Impact

- Новый пакет `packages/desktop` (Electron, electron-builder).
- `packages/server`: запуск сервера из чужого процесса без CLI-обёртки и выбор
  CLI OpenSpec — из репозитория или встроенный.
- `packages/web`: разметка под окно приложения без адресной строки, переход по
  внешним ссылкам — в системный браузер.
- Сборка: для установщика нужен двоичный Electron; в закрытой корпоративной
  сети он берётся с зеркала (`ELECTRON_MIRROR`).
- Зависит от `add-openspec-ide`: оболочка отдаёт тот же интерфейс.
