# Spec Delta: desktop-shell

## Purpose

Делает OpenSpec IDE обычным десктопным приложением: устанавливается одним
установщиком, работает в собственном окне, открывает репозитории через
стартовый экран и системный диалог и не требует ни браузера, ни консоли.

## ADDED Requirements

### Requirement: Установка и запуск приложения

Система ДОЛЖНА (SHALL) поставляться установщиком для Windows и переносимой сборкой, не
требующей установки, а также сборками для macOS и Linux. Установленное
приложение ДОЛЖНО запускаться ярлыком без окна консоли и без установленного
отдельно Node.js.

#### Scenario: Установка на Windows

- **WHEN** пользователь запускает установщик на машине без Node.js
- **THEN** приложение устанавливается в профиль пользователя без прав администратора
- **AND** в меню «Пуск» и на рабочем столе появляется ярлык OpenSpec IDE

#### Scenario: Запуск ярлыком

- **WHEN** пользователь запускает приложение ярлыком
- **THEN** открывается окно приложения со стартовым экраном
- **AND** ни окно консоли, ни вкладка браузера не открываются

#### Scenario: Переносимая сборка

- **WHEN** пользователь распаковывает переносимую сборку и запускает исполняемый файл
- **THEN** приложение работает так же, как установленное
- **AND** в систему ничего не записывается, кроме каталога пользовательских настроек приложения

### Requirement: Стартовый экран и открытие репозитория

Система ДОЛЖНА (SHALL) показывать при запуске без аргументов стартовый экран со списком
недавних репозиториев и действием открытия папки через системный диалог. Корень
OpenSpec ДОЛЖЕН определяться от выбранной папки поиском вверх по дереву, как в
команде `openspec-ide`.

#### Scenario: Открытие папки

- **WHEN** пользователь выбирает в системном диалоге папку внутри репозитория с `openspec/`
- **THEN** открывается рабочее пространство с корнем в ближайшем каталоге, содержащем `openspec/`
- **AND** репозиторий добавляется в начало списка недавних

#### Scenario: Недавний репозиторий

- **WHEN** пользователь выбирает репозиторий из списка недавних
- **THEN** рабочее пространство открывается без системного диалога

#### Scenario: Недавний репозиторий больше не существует

- **WHEN** папка из списка недавних удалена или недоступна
- **THEN** элемент списка помечен как недоступный
- **AND** предлагается убрать его из списка

#### Scenario: В папке нет OpenSpec

- **WHEN** в выбранной папке и выше по дереву нет каталога `openspec/`
- **THEN** приложение предлагает завести OpenSpec в выбранной папке командой `openspec init`
- **AND** после согласия и успешной инициализации открывает рабочее пространство

### Requirement: Окна репозиториев

Система ДОЛЖНА (SHALL) открывать каждый репозиторий в отдельном окне, в заголовке
которого указано имя репозитория. Одновременно ДОЛЖЕН работать не более одного
экземпляра приложения.

#### Scenario: Два репозитория

- **WHEN** пользователь открывает второй репозиторий
- **THEN** он открывается в новом окне, первое окно остаётся открытым
- **AND** заголовки окон называют каждое свой репозиторий

#### Scenario: Повторное открытие того же репозитория

- **WHEN** пользователь открывает репозиторий, окно которого уже открыто
- **THEN** новое окно не создаётся, фокус переходит на существующее

#### Scenario: Второй запуск приложения

- **WHEN** приложение уже запущено и пользователь запускает его снова, в том числе с путём к репозиторию
- **THEN** новый экземпляр не создаётся
- **AND** работающий экземпляр открывает переданный репозиторий или показывает стартовый экран

#### Scenario: Положение и размер окна

- **WHEN** пользователь закрывает окно репозитория и открывает его снова
- **THEN** окно появляется с прежними размером и положением
- **AND** если прежнее положение за пределами подключённых мониторов, окно размещается на основном

### Requirement: Встроенный сервер

Система ДОЛЖНА (SHALL) запускать сервер IDE внутри процесса приложения на
loopback-интерфейсе с токеном сессии и показывать интерфейс только в окне
приложения. Переходы на внешние адреса ДОЛЖНЫ открываться в системном браузере.

#### Scenario: Интерфейс в окне

- **WHEN** открывается рабочее пространство
- **THEN** интерфейс загружается в окно приложения с адреса loopback-сервера этого окна
- **AND** браузер не открывается

#### Scenario: Внешняя ссылка

- **WHEN** пользователь переходит по ссылке на внешний адрес
- **THEN** ссылка открывается в системном браузере
- **AND** окно приложения остаётся на интерфейсе IDE

#### Scenario: Закрытие окна

- **WHEN** пользователь закрывает окно репозитория
- **THEN** сервер этого окна останавливается, наблюдение за файлами прекращается

### Requirement: Встроенный CLI OpenSpec

Система ДОЛЖНА (SHALL) включать CLI OpenSpec в поставку приложения и использовать его,
когда в репозитории нет своей версии. Версия из репозитория ДОЛЖНА иметь
приоритет над встроенной.

#### Scenario: CLI есть в репозитории

- **WHEN** в репозитории установлен `@fission-ai/openspec`
- **THEN** приложение использует версию репозитория
- **AND** в строке состояния указано, какой CLI используется и его версия

#### Scenario: CLI в репозитории нет

- **WHEN** в репозитории и в PATH нет CLI OpenSpec
- **THEN** приложение использует встроенный CLI без дополнительных действий пользователя

### Requirement: Меню и горячие клавиши

Система ДОЛЖНА (SHALL) предоставлять системное меню приложения с действиями открытия
репозитория, списком недавних, переключением разделов и закрытием окна, а
также горячие клавиши для основных действий.

#### Scenario: Открытие из меню

- **WHEN** пользователь выбирает в меню «Файл → Открыть репозиторий…» или нажимает Ctrl+O
- **THEN** появляется системный диалог выбора папки

#### Scenario: Переключение разделов

- **WHEN** пользователь выбирает раздел в меню «Вид» или нажимает его сочетание клавиш
- **THEN** окно переключается на этот раздел

### Requirement: Закрытие при выполняющемся запуске агента

Система ДОЛЖНА (SHALL) запрашивать подтверждение при закрытии окна или выходе из
приложения, пока в этом окне выполняется запуск агента, и останавливать запуск
с сохранением его показателей после подтверждения.

#### Scenario: Закрытие во время запуска

- **WHEN** пользователь закрывает окно, в котором выполняется запуск агента
- **THEN** показывается предупреждение с названием выполняющегося запуска
- **AND** при подтверждении запуск останавливается и помечается прерванным, затем окно закрывается
- **AND** при отказе окно остаётся открытым, запуск продолжается
