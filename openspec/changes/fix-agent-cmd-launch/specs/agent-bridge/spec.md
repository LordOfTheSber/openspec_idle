# Spec Delta: agent-bridge

## ADDED Requirements

### Requirement: Запуск CLI через обёртки .cmd на Windows

Система ДОЛЖНА (SHALL) на Windows запускать CLI, установленный обёрткой `.cmd`,
так, чтобы многострочный промпт доходил до CLI без искажений: разбирать
обёртку и запускать напрямую то, что она вызывает (скрипт Node или `.exe`), а
если разобрать обёртку не удалось — запускать её через `cmd.exe`, передавая
промпт на стандартный ввод. Нераспознанная обёртка НЕ ДОЛЖНА блокировать запуск
агента.

#### Scenario: Обёртка установщика со своим Node

- **WHEN** `gigacode.cmd` вызывает `"%~dp0node\node.exe" "%~dp0lib\cli.js" %*`
- **THEN** агент запускается этим `node.exe` со скриптом `lib\cli.js` без `cmd.exe`
- **AND** промпт передаётся аргументом целиком

#### Scenario: Обёртку разобрать не удалось

- **WHEN** обёртка вызывает то, что нельзя свести к скрипту Node или `.exe`
- **THEN** агент запускается через `cmd.exe`, а промпт уходит на стандартный ввод
- **AND** проверка подключения показывает пометку со строкой запуска из обёртки

#### Scenario: Аргумент нельзя передать через cmd.exe

- **WHEN** при запуске через `cmd.exe` дополнительный аргумент содержит перевод строки, кавычку или `%`
- **THEN** запуск не выполняется, а сообщение называет этот аргумент
