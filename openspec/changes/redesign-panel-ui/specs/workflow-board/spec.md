## MODIFIED Requirements

### Requirement: Содержимое карточки change

Карточка change ДОЛЖНА (SHALL) показывать имя change, имя его схемы, время
последнего изменения файлов change, нить change с состоянием артефактов и
прогрессом по отслеживаемому артефакту, подпись состояния, результат последней
валидации иконкой, цветом и текстом и одно следующее действие: «Создать
<артефакт>» для первого отсутствующего артефакта или «Архивировать» в колонке
«Готово к архивации». Узел созданного артефакта на нити ДОЛЖЕН открывать его
файл: в VS Code — в редакторе VS Code, в браузере — во встроенном редакторе.

#### Scenario: Карточка с ошибками валидации

- **WHEN** последняя валидация change завершилась с ошибками
- **THEN** карточка показывает признак ошибки и их количество
- **AND** переход с карточки открывает панель проверок этого change

#### Scenario: Карточка нового change

- **WHEN** change создан только что и ни разу не валидировался
- **THEN** карточка показывает состояние проверки «не проверялся»
- **AND** доступно действие запуска валидации

#### Scenario: Время изменения

- **WHEN** файлы change последний раз менялись пять минут назад
- **THEN** карточка показывает «изменён 5 мин назад»

#### Scenario: Переход к артефакту с карточки

- **WHEN** пользователь в панели VS Code щёлкает узел `design` на нити карточки
- **THEN** `design.md` этого change открывается в редакторе VS Code

#### Scenario: Следующее действие — создать артефакт

- **WHEN** у change нет `design.md`, а карточка в колонке design
- **THEN** на карточке есть действие «design.md», которое создаёт артефакт по шаблону схемы

#### Scenario: Прогресс на карточке

- **WHEN** выполнено 2 пункта плана из 4
- **THEN** подпись карточки содержит «2/4 пунктов»

### Requirement: Раскладка доски в узкой панели

Доска ДОЛЖНА (SHALL) занимать всю ширину раздела без дерева рабочего
пространства. Над колонками ДОЛЖНА идти полоса всех фаз со счётчиками карточек;
колонки ДОЛЖНЫ показываться только для фаз с карточками, если пользователь не
включил «Пустые фазы», а щелчок по пустой фазе в полосе ДОЛЖЕН разворачивать её
колонку. Доска ДОЛЖНА иметь режим «Список», в котором непустые фазы идут
секциями сверху вниз, а пустые перечислены одной строкой, и в автоматическом
режиме переключаться в него, когда ширина доски меньше 640 px. Выбор режима и
показ пустых фаз ДОЛЖНЫ сохраняться между открытиями доски.

#### Scenario: Пустые колонки свёрнуты

- **WHEN** на доске семь фаз и карточки есть только в двух
- **THEN** показаны две колонки, а полоса фаз показывает все семь со счётчиками
- **AND** щелчок по пустой фазе в полосе разворачивает её колонку

#### Scenario: Узкая панель VS Code

- **WHEN** панель разделов открыта рядом с редактором и доска уже 640 px
- **THEN** доска показана списком фаз без горизонтальной прокрутки
- **AND** в каждой секции видны карточки этой фазы

#### Scenario: Режим выбран вручную

- **WHEN** пользователь выбрал режим «Колонки» и закрыл панель
- **THEN** при следующем открытии доска показана колонками независимо от ширины

#### Scenario: Фильтр по имени

- **WHEN** пользователь вводит часть имени change в поле фильтра
- **THEN** на доске остаются только карточки, имя которых содержит введённый текст
- **AND** счётчики фаз показывают число оставшихся карточек

### Requirement: Панель деталей change

Выбор карточки ДОЛЖЕН (SHALL) открывать панель деталей change рядом с доской,
а на узкой панели — поверх доски. Панель ДОЛЖНА показывать нить change с
подписями и вкладки: «Обзор» — готовность к архивации, артефакты с состоянием
и переходом к файлу, затронутые спеки; «План» — пункты отслеживаемого
артефакта по группам с возможностью отметки; «Проверка» — результат последней
проверки, запущенной с доски, и предпросмотр архивации; «Трассировка» — переход
к трассировке этого change. Панель ДОЛЖНА предлагать действия: проверить,
открыть дельты и метрики этого change, архивировать; главной кнопкой
«Архивировать…» ДОЛЖНА быть только в колонке «Готово к архивации». Готовность
к архивации ДОЛЖНА складываться из пяти условий: артефакты созданы, план
выполнен, валидация без ошибок, все сценарии покрыты, предпросмотр архивации —
«пройдёт». Панель ДОЛЖНА закрываться кнопкой и клавишей Esc.

#### Scenario: Переход к метрикам

- **WHEN** пользователь нажимает «Метрики» в панели деталей change
- **THEN** открывается раздел «Метрики» с этим change

#### Scenario: Пункты по группам

- **WHEN** отслеживаемый артефакт содержит группы `## 1.` и `## 2.`
- **THEN** на вкладке «План» пункты показаны под заголовками своих групп

#### Scenario: Готовность к архивации

- **WHEN** у change созданы все артефакты, выполнен план и последняя валидация чистая, а покрыты 4 сценария из 5
- **THEN** готовность показывает 3 выполненных условия из 5
- **AND** у условия покрытия указано «4/5»

#### Scenario: Закрытие по Esc

- **WHEN** панель деталей открыта и пользователь нажимает Esc
- **THEN** панель закрывается, а доска остаётся на месте
