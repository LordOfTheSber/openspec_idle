# Контекст модуля web

Пакет `@openspec-ide/web`: React 19 + Vite. Одна страница с вкладками
разделов; в VS Code она живёт в webview, в разработке — во вкладке браузера.

## Транспорт

Разделы вызывают функции `src/lib/api.ts` и не знают, где бэкенд.
`src/lib/transport.ts` даёт два транспорта с одинаковыми кодами и телами
ответов: `fetch` с токеном сессии и сообщения webview с нумерацией запросов.
Хост определяется в `src/lib/host.ts`; открыть файл в редакторе можно только в
VS Code (`openInEditor`).

## Разделы

`src/App.tsx` — шапка с вкладками, палитра Ctrl+K, проверка ревизии API.
Разделы — `src/components/`: доска и детали change, «Дельты» с трассировкой,
«Метрики», «Контекст» (граф, матрица, вид «Контроль» в
`src/components/ContextControl.tsx`), «Структура», «Процессы» (конструктор
схем). Раскладки графов — чистые функции в `src/lib/` с тестами.

## Правила

- Строки интерфейса — на русском, числа и склонения — через
  `src/lib/format.ts` (`plural`, `formatTokens`).
- Состояние окна (вид, выбор, флажки) — в `localStorage` через
  `src/lib/prefs.ts`; состояние проекта — только с бэкенда.
- Цвета — переменные из `src/styles.css`; в VS Code они берутся из темы
  редактора, поэтому свои цвета не задаются.
- Элементы, которые проверяет e2e, несут `data-testid`.
