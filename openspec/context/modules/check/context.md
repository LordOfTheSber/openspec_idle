# Контекст модуля check

Пакет `openspec-ide-check`: консольная команда, после сборки (`build.mjs`) —
один файл `openspec-ide-check.mjs` в каталоге `dist`. Проверки выполняет
`runCheck()` из `server` через встроенный бэкенд — те же маршруты, что видит
расширение, поэтому правила CI и IDE не расходятся.

- `src/cli.ts` — точка входа: аргументы, вывод, код завершения.
- `src/report.ts` — разбор аргументов (`--only`, `--skip`, `--format`,
  `--fail-on`, `--root`, `--cli`) и форматы `text`, `json`, `github`
  (аннотации GitHub Actions).
- Проверка `quality` добавляет к замечанию имя правила в скобках, а к итогу —
  строку метрик качества спеков (в `json` — поле `metrics` проверки).
- Код завершения: 0 — нет замечаний на уровне порога и выше, 1 — есть,
  2 — ошибка запуска. Сведения по умолчанию проверку не роняют.
- Проверки, которым нужен CLI OpenSpec, при его отсутствии дают ошибку запуска
  с подсказкой `--skip`; без `openspec/context/modules` проверка `context`
  пропускается.

Требования к команде — в незаархивированном change `add-conformance-check`.
