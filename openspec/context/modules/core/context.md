# Контекст модуля core

Пакет `@openspec-ide/core`: типы и чистые функции, которыми пользуются сервер,
страница, расширение и CI. Получает уже прочитанные данные, возвращает модель и
замечания; файловой системы, процессов и сети здесь нет.

## Инварианты

- Ни одного `node:*` и внешнего пакета: `core` попадает в сборку страницы.
  Нарушение ловит `src/purity.test.ts`, а не сборка.
- Функции детерминированы: время, чтение каталогов и проверка существования
  путей приходят параметрами (`now`, «ключ → строка», множество существующих
  путей).
- Публичный API — только то, что экспортирует `src/index.ts`.
- Анализ текста файла контекста запоминается по тексту в `src/textCache.ts`
  (`estimateTokens`, `extractReferences`, `textReferenceCandidates`,
  `isEmptyContext`, абзацы, `measureUsefulness` с параметрами в ключе,
  `findTokenAntipatterns`): функции остаются чистыми, тексты короче 2 КБ не
  запоминаются, объём ограничен 32 млн символов. Результаты из кэша общие —
  не меняйте их, типы `readonly`. Новый расчёт по тексту целого файла —
  через `textCache.get` с уникальным видом расчёта.

## Что где

| Файл | Что делает |
| --- | --- |
| `src/board.ts` | фазы доски из схемы и статусов артефактов |
| `src/delta.ts`, `src/specChange.ts`, `src/textDiff.ts` | разбор дельт, эффект change на спек, построчное сравнение (LCS) |
| `src/trackedItems.ts`, `src/metrics.ts`, `src/acceptance.ts` | пункты плана, снимок метрик из журнала событий, проверка приёмки |
| `src/sdd.ts`, `src/schemaDocument.ts`, `src/schemaPreview.ts` | правила SDD и правка схемы процесса |
| `src/structure.ts` | проверка раскладки по `openspec/structure.yaml` |
| `src/contextMap.ts`, `src/contextControl.ts`, `src/contextAntipatterns.ts` | карта модулей, доменов и ADR, набор контекста, объём, полезность, антипаттерны по токенам, лишнее, ссылки |
| `src/trace.ts`, `src/authoring.ts`, `src/drift.ts` | трассировка `↳`, помощь в редакторе, пересечения и устаревшие дельты |
| `src/workspaceTree.ts`, `src/search.ts` | дерево рабочего пространства и поиск |
| `src/hostProtocol.ts`, `src/constants.ts` | сообщения панель ↔ хост, `API_REVISION` |

## Как менять

- Новое правило — функция с тестом рядом (`*.test.ts`), затем вызов из сервера
  и показ в интерфейсе.
- Поле, которое понадобилось интерфейсу, — повод поднять `API_REVISION`:
  панель сверяет её с бэкендом и честно говорит «перезагрузите окно».
- Разбор `tasks.md` повторяет правило CLI (скобки с `x` в любом регистре);
  расхождение ловят фикстурные тесты, сверяющие счётчики с `openspec list`.
