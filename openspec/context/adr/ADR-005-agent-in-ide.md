# ADR-005: Агент GigaCode запускается из IDE

## Решение (отменено)

IDE запускала GigaCode CLI как управляемую операцию: промпт из инструкций
OpenSpec, потоковый вывод, бюджет, журнал запусков и привязка результата к
пункту плана. Описание запуска переопределялось в `.openspec-ide/config.json`.

## Почему отменено

Агентов команда запускает сама — в терминале или своём редакторе; запуск из
IDE оказался лишним слоем. Не хватало другого — управляемого контекста. См.
ADR-006.
