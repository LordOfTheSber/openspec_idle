# ADR-002: Бэкенд в процессе расширения через inject() Fastify

## Контекст

Маршруты бэкенда уже были описаны как Fastify-приложение. Поднимать его на
порту внутри VS Code значит пробрасывать порт в удалённых сценариях, держать
токен и ослаблять CSP панели до `http://127.0.0.1:*`.

## Решение

`createEmbeddedBackend()` собирает то же приложение без порта и обслуживает
запросы панели через `app.inject()`: маршруты, хуки и обработчик ошибок
работают в памяти. Токен сессии бэкенд прикладывает сам. HTTP-режим остаётся
для разработки интерфейса.

## Рассмотренная альтернатива

Набор RPC-функций вместо маршрутов: чище, но проверки аргументов и перевод
ошибок в коды пришлось бы поддерживать дважды.

## Последствия

- Панель запрещает сеть целиком (`connect-src 'none'`).
- `openspec-ide-check` использует тот же встроенный бэкенд — правила CI и IDE
  совпадают по построению.
