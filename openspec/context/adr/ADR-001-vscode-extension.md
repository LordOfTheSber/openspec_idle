# ADR-001: Расширение VS Code вместо отдельной web-IDE

## Контекст

Первая версия была самостоятельной web-средой: бинарь `openspec-ide`, локальный
сервер и вкладка браузера со своим редактором артефактов. Команда при этом
правила те же файлы в VS Code — два редактора одних файлов давали конфликты, а
среда требовала порта и токена.

## Решение

IDE — расширение VS Code. Нативно — то, для чего у редактора есть механизм:
дерево, редактирование, диагностика, команды. Доска, дельты, метрики, контекст,
структура и процессы — React-разделы в одной панели webview. Пакет
`packages/cli` упразднён.

## Последствия

- Артефакты правятся обычным редактором; IDE подсказывает и проверяет.
- Интерфейс разделов не знает хоста: транспорт сменяемый, в разработке он же
  работает в браузере.
- Требования прежней среды — архивный change
  [add-openspec-ide](../../changes/archive/2026-09-24-add-openspec-ide/proposal.md),
  переезд — [add-vscode-extension](../../changes/archive/2026-09-24-add-vscode-extension/design.md).
