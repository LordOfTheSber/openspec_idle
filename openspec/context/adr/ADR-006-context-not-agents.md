# ADR-006: IDE готовит контекст, а не запускает агентов

## Решение

Раздел агента, маршруты `/api/agent/*` и настройки подключения удалены. Вместо
них — модель контекста в `openspec/context/`: общий контекст, модули с
доменами, зависимостями и путями кода, ADR. IDE проверяет связи, собирает набор
файлов для задачи (строки `@путь` для агента в терминале) и контролирует сам
контекст: объём в токенах, повторы, пропавшие пути, отставание от кода.

## Рассмотренная альтернатива

Оставить запуск агента и добавить к нему контекст: две возможности вместо
одной, при том что первой не пользуются.

## Последствия

- Метрики расхода токенов агентом больше не пополняются, показывается история.
- Спек `agent-bridge` удаляется при архивации change `focus-context-map`.
