# ADR-004: Чистый core без Node API

## Решение

Модель и правила — в `packages/core`, без `node:*` и внешних пакетов. Сервер
читает файлы, разбирает YAML и зовёт процессы, а в `core` передаёт готовые
значения и функции («ключ → строка», множество существующих путей). Правило
проверяет тест чистоты, а не соглашение.

## Рассмотренная альтернатива

Общий пакет с Node-зависимостями и отдельная «браузерная» часть: проще писать,
но нарушение всплывает только при сборке страницы, а правило — копируется.

## Последствия

- Одни и те же функции считают замечания на сервере и выводы в панели.
- Логика тестируется без файловой системы и процессов.
