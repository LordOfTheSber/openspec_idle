# OpenSpec IDE для VS Code

Работа по методологии [OpenSpec](https://github.com/Fission-AI/OpenSpec) прямо в
VS Code: дерево changes, спеков, процессов и архива, замечания
`openspec validate --strict` в панели «Проблемы», доска процесса, дельты спеков,
метрики по каждому пункту плана, конструктор собственного процесса с проверкой
SDD, проверка структуры папок и карта контекста: модули из
`openspec/context/modules/`, их домены (спеки), зависимости и ADR — графом и
матрицей, с замечаниями в панели «Проблемы». В редакторе — дополнение имён
требований и ссылок плана, проверка ссылок дельт на основной спек, быстрые
исправления, переход и подсказки над строками; основные спеки проверяются так
же, как changes; пересечения changes и устаревшие дельты видны на доске и в
«Проблемах», готовые changes архивируются пакетом.

Источник истины — файлы `openspec/` и CLI `@fission-ai/openspec`. Расширение не
открывает сетевых портов: бэкенд работает внутри процесса расширения.

## Требования

- VS Code 1.90 и новее;
- CLI OpenSpec в проекте (`npm install -D @fission-ai/openspec@1.13.1`) или в `PATH`.

## Как пользоваться

Откройте папку проекта с каталогом `openspec/` — на панели действий появится
значок OpenSpec. Выбор артефакта в дереве открывает его в редакторе; у change в
контекстном меню — проверка, архивация, метрики и дельты. Карта контекста —
команда «OpenSpec: Карта контекста». Все команды —
в палитре по префиксу «OpenSpec:».

Подробности — в README репозитория.
