«Качество» на этом проекте — по файлам

Новый раздел панели между «Метриками» и «Контекстом». Сверху — четыре метрики проекта, под ними — фильтр по уровню, группировка и поиск. Слева — все правила по группам с числом замечаний: щелчок фильтрует список, правила без замечаний — бледные. Справа — файлы по убыванию предупреждений: спеки, дельты и артефакты changes (design.md — из-за правил артефактов) с метриками каждого. Данные — реальные: 51 предупреждение и 68 сведений этого репозитория.
